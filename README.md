# GisFind-бесплатно (Telegram-бот)

Ищет организации по нише и городу одновременно через два официальных API:
**2GIS Catalog API** (demo-ключ) и **Яндекс.Карты — Поиск по организациям**
(бесплатно до 500 запросов/сутки). Показывает только тех, у кого есть хотя бы
телефон, и умеет отдельно фильтровать тех, у кого нет сайта.

## Чем отличается от GisFind

| | GisFind | Этот бот |
|---|---|---|
| Название, адрес, категория, рейтинг | ✅ | ✅ |
| Телефон | ✅ | ✅, но **только из Яндекса** (см. ниже) |
| WhatsApp / Instagram / Telegram | ✅ (платно/по регистрации) | ❌ — таких полей нет ни в одном бесплатном API |
| Источники | 2GIS | 2GIS + Яндекс.Карты |
| Стоимость | платный сервис | бесплатно |

### Почему телефон есть не у всех и в основном из Яндекса

По [документации 2GIS](https://docs.2gis.com/en/api/search/overview) контактные
данные организаций (`contact_groups`) — платная опция, **не отдаётся на
demo-ключе**. У Яндекс.Карт телефон в бесплатном API есть (поле `Phones`), это
подтверждено их [документацией](https://yandex.ru/dev/maps/geosearch/). Поэтому
бот всегда фильтрует результаты — оставляет только тех, у кого есть телефон, —
и по факту это почти всегда карточки из Яндекса, а не из 2GIS.

WhatsApp/Instagram/Telegram как отдельные контактные поля не документированы
ни у 2GIS (даже на платной подписке я такого явно не видел в документации),
ни у Яндекса — поэтому бот ориентируется только на обычный номер телефона.

### Если нужны именно WhatsApp/Instagram/Telegram-контакты

Официального бесплатного способа их получить нет. Реальные варианты:
1. Купить подписку 2GIS API Platform (https://platform.2gis.ru) — там в
   `contact_groups` иногда есть мессенджеры, но нужно проверять на месте.
2. Скрапить сайты 2gis.ru / yandex.ru/maps напрямую — прямое нарушение их
   пользовательских соглашений (у Яндекса это вообще написано явным текстом —
   нельзя сохранять/переиспользовать данные из API), плюс активная защита от
   ботов. Я сознательно не стал делать такой парсер "под ключ" — слишком
   хрупко и рискованно юридически, особенно если результат планируется
   использовать для массовых рассылок (это уже вопрос закона о рекламе,
   152-ФЗ о персональных данных и правил самих WhatsApp/Instagram/Telegram
   насчёт спама и автоматических обращений без согласия).

### Лицензионный нюанс Яндекс.Карт

Яндекс прямо указывает, что данные из API Поиска по организациям нельзя
сохранять или переиспользовать как отдельную базу — только показывать
результат в ответ на запрос пользователя. Бот именно так и работает: ничего
не сохраняет в базу, просто пересылает ответ в чат по вашему запросу.

## Установка

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Получите токен Telegram-бота у [@BotFather](https://t.me/BotFather)
   (команда `/newbot`).
3. Получите бесплатный demo-ключ 2GIS на https://dev.2gis.com
   (кнопка «Получить демо-ключ» → регистрация в Platform Manager).
   Учтите: demo-ключ обычно выдаётся на ограниченный тестовый период —
   уточняйте актуальные условия у 2GIS при регистрации.
3.1. Получите бесплатный ключ Яндекс.Карт на https://yandex.ru/dev/maps/geosearch/
   (нужен обычный Яндекс-аккаунт, карта не требуется). Именно этот ключ даёт
   боту телефоны — без него фильтр "с контактами" почти всегда будет пустым.
4. Скопируйте `.env.example` в `.env` и впишите все три значения:
   ```
   cp .env.example .env
   ```
5. Запустите бота:
   ```
   python bot.py
   ```

## Использование

- `/start` — приветствие и пояснение об ограничениях
- `/find` — бот спросит нишу, потом город, и пришлёт список организаций
- Кнопка «Показать ещё» — следующая страница (максимум 5 страниц)

## Где держать бота постоянно включённым

Локальный `python bot.py` работает только пока открыт компьютер. Варианты
для постоянной работы:
- Дешёвый VPS (от ~150–300 руб/мес) — залить проект, запустить через
  `systemd` или `screen`/`tmux`, чтобы бот работал после отключения от SSH.
- Бесплатные PaaS с ограничениями (Render.com, Railway.app — free-тир может
  «усыплять» процесс без входящего трафика; для polling-бота это иногда
  проблема, надёжнее платный минимальный тариф или свой VPS).

## Правовой нюанс на будущее

Если позже всё же добавите сбор контактов и рассылки по ним — это уже
холодный маркетинг/спам-зона: в РФ есть 152-ФЗ (персональные данные) и
закон о рекламе (согласие на рекламные рассылки), а WhatsApp Business и
Instagram банят аккаунты за автоматизированные массовые обращения без
согласия получателя. Стоит иметь это в виду до масштабирования.
