# GisFind-бесплатно (Telegram-бот)

Ищет организации по нише и городу через официальный **2GIS Catalog API**
(demo-ключ, бесплатно).

## Чем отличается от GisFind

| | GisFind | Этот бот |
|---|---|---|
| Название, адрес, категория, рейтинг | ✅ | ✅ |
| Телефон / WhatsApp / Instagram | ✅ (платно/по регистрации) | ❌ |
| Стоимость | платный сервис | бесплатно |
| Кол-во результатов за раз | до 150+ | до 50 (лимит demo-ключа: 5 страниц × 10) |

Причина отсутствия телефонов: по [документации 2GIS](https://docs.2gis.com/en/api/search/overview)
контактные данные организаций — платная опция и **не отдаются на demo-ключе**.
Официального бесплатного способа получить телефоны через 2GIS не существует.

Если телефоны критичны, два реальных варианта:
1. Купить подписку 2GIS API Platform (https://platform.2gis.ru) — контактные
   поля появятся автоматически, менять код почти не придётся.
2. Скрапить сайт 2gis.ru напрямую — но это прямое нарушение пользовательского
   соглашения 2GIS, у них активная защита от ботов (JS-рендеринг, антибот),
   и такой парсер может в любой момент перестать работать. Я сознательно не
   стал делать этот вариант "под ключ" — слишком хрупко и рискованно юридически,
   особенно если результат планируется использовать для массовых рассылок
   (это уже вопрос закона о рекламе/персональных данных и правил самих
   WhatsApp/Instagram насчёт спама).

## Установка

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Получите токен Telegram-бота у [@BotFather](https://t.me/BotFather)
   (команда `/newbot`).
3. Получите бесплатный demo-ключ 2GIS на https://dev.2gis.com
   (кнопка «Получить демо-ключ» → регистрация в Platform Manager).
   Учтите: demo-ключ обычно выдаётся на ограниченный тестовый период —
   уточняйте актуальные условия у 2GIS при регистрации.
4. Скопируйте `.env.example` в `.env` и впишите оба значения:
   ```
   cp .env.example .env
   ```
5. Запустите бота:
   ```
   python bot.py
   ```

## Использование

- `/start` — приветствие и пояснение об ограничениях
- `/find` — бот спросит нишу, потом город, и пришлёт список организаций
- Кнопка «Показать ещё» — следующая страница (максимум 5 страниц)

## Где держать бота постоянно включённым

Локальный `python bot.py` работает только пока открыт компьютер. Варианты
для постоянной работы:
- Дешёвый VPS (от ~150–300 руб/мес) — залить проект, запустить через
  `systemd` или `screen`/`tmux`, чтобы бот работал после отключения от SSH.
- Бесплатные PaaS с ограничениями (Render.com, Railway.app — free-тир может
  «усыплять» процесс без входящего трафика; для polling-бота это иногда
  проблема, надёжнее платный минимальный тариф или свой VPS).

## Правовой нюанс на будущее

Если позже всё же добавите сбор контактов и рассылки по ним — это уже
холодный маркетинг/спам-зона: в РФ есть 152-ФЗ (персональные данные) и
закон о рекламе (согласие на рекламные рассылки), а WhatsApp Business и
Instagram банят аккаунты за автоматизированные массовые обращения без
согласия получателя. Стоит иметь это в виду до масштабирования.
